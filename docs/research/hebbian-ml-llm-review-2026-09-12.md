**Hebbian Learning and Brain-Inspired Approaches for Machine Learning and Language Models**

Hebbian ideas have practical value in machine learning, especially for associative memory, fast adaptation, and selecting which representations to modify. The strongest evidence relevant to modern language models comes from combining these mechanisms with gradient-trained representations. This includes delta-rule recurrent memory in large model architectures, learned test-time memory, and smaller interventions in fine-tuning or retrieval. The reviewed literature does not establish that a purely local, two-factor Hebbian rule can replace backpropagation for competitive general-purpose LLM pretraining. This is an assessment of the available evidence, rather than an impossibility claim. <sup>[13](https://arxiv.org/abs/2209.11883), [29](https://arxiv.org/abs/2102.11174), [39](https://arxiv.org/abs/2510.26692), [40](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Thinking)</sup>

This review covers foundational work and recent literature available through **September 12, 2026**, with particular attention to 2024–2026. It is a broad, critical scoping review, not an exhaustive systematic review of every online publication. It includes original papers, conference proceedings, and official model documentation. Biological mechanisms, mathematical equivalences, benchmark results, and architectural adoption are treated as different types of evidence. Recent preprints are identified separately from confirmed conference or journal publications; results are author-reported unless explicitly described otherwise. A linked, annotated inventory of 54 sources accompanies the analysis.

**The distinction that makes this literature easier to read.** “Hebbian” can describe several different things: the rule that trains permanent weights; a temporary memory update inside a model; a rule learned through meta-learning; an interpretation of attention; or a heuristic for connecting retrieved documents. These meanings should not be combined into a single claim about how a model learns. In particular, a model can contain a local Hebbian memory update while its embeddings, gates, projections, and readout are trained with ordinary backpropagation. <sup>[14](https://proceedings.mlr.press/v80/miconi18a.html), [29](https://arxiv.org/abs/2102.11174), [46](https://aclanthology.org/2026.findings-acl.954/), [47](https://aclanthology.org/2026.acl-long.625/)</sup>

| Family | What changes? | Where does the learning signal come from? | Evidence relevant to ML/LLMs |
|---|---|---|---|
| Classical Hebbian/Oja/competitive learning | Representation weights | Local activity, normalization, competition | Established feature-learning principles; limited evidence for replacing full LLM training [1–3, 10–13] |
| Three-factor and feedback-based learning | Weights or eligibility traces | Local activity plus reward, error, or feedback | Useful approaches to credit assignment; global-signal assumptions matter [6, 18–22, 44] |
| Fast weights and differentiable plasticity | Temporary connection strengths | Correlation or prediction error; often a learned gate | Demonstrated rapid memory and adaptation with a gradient-trained outer loop [8–9, 14–16] |
| Linear attention and delta-rule recurrence | A matrix-valued sequence state | Token-derived keys, values, gates, and retrieval errors | Strongest evidence of scaling into large LM architectures [28–31, 37–41] |
| TTT, Titans, MIRAS, Hope | A trainable memory or selected model weights during context processing | An inner optimization objective | Promising language-model experiments; gradient-based inner and outer learning remain common [32–36] |
| Hebbian-inspired parameter-efficient tuning | Adapters, rank allocation, or selected layers | Activations and, often, output gradients | Direct LLM fine-tuning results with narrower claims than replacing backprop [45–46] |
| Associative agent memory | External memory graph and summaries | Co-activation, retrieval, and consolidation | Applicable to existing LLM agents without changing their base weights [47] |
| Spiking networks | Activity representation; sometimes weights | STDP, eligibility traces, or surrogate gradients | Potential hardware benefits; spiking activity alone does not imply Hebbian training [5, 22, 42] |

The reference numbers in tables point to the source inventory at the end. They describe representative evidence, not an exhaustive membership list for each family.

**The mathematical connection.** Let an input neuron have activity \(x_i\), an output neuron have activity \(y_j\), and their connection have weight \(w_{ji}\). A simple rate-based Hebbian update is

\[
\Delta w_{ji}=\eta y_jx_i.
\]

This correlational update alone does not specify which features will help predict a target. In a linear neuron, repeated reinforcement can also cause weight growth. Oja's rule adds stabilization:

\[
\Delta w_{ji}=\eta y_j(x_i-y_jw_{ji}).
\]

For a single linear neuron, appropriately centered stationary inputs, and suitable learning-rate and convergence conditions, this learns a leading principal-component direction. Without centering, the relevant matrix is the input second moment rather than covariance. Sanger's generalized rule extends the idea to multiple principal components. These are substantial learning results, but maximizing variance or capturing correlations does not itself solve deep supervised credit assignment. <sup>[1](https://pubmed.ncbi.nlm.nih.gov/7153672/), [3](https://www.sciencedirect.com/science/article/pii/0893608089900440)</sup>

A three-factor rule adds a modulator:

\[
\Delta w_{ji}(t)=\eta m_j(t)e_{ji}(t),
\]

where \(e_{ji}\) is a local eligibility trace and \(m_j\) can encode reward or error information. This separates “which connection was recently involved?” from “should the recent involvement be reinforced?” The biological inspiration is richer than activity correlation alone: timing, homeostasis, inhibition, dendritic compartments, and neuromodulation all affect plasticity. <sup>[2](https://www.cnbc.cmu.edu/~tai/nc19journalclubs/BCM_paper1982.pdf), [5](https://pubmed.ncbi.nlm.nih.gov/9852584/), [6](https://pubmed.ncbi.nlm.nih.gov/17220510/), [21](https://elifesciences.org/articles/22901)</sup>

For language models, replace individual synapses with a fast memory matrix \(M_t\). Let \(k_t\) be a key and \(v_t\) its associated value. An additive write is

\[
M_t=M_{t-1}+\eta_t v_tk_t^\top,
\qquad \hat v=M_tq.
\]

This is the outer-product form of a Hebbian association. With \(\eta_t=1\), it is the recurrent accumulator underlying unnormalized linear attention. Positive-kernel normalized linear attention additionally maintains a denominator state, so the equation should not be presented as all of normalized attention. Nor is it generally identical to ordinary softmax attention. <sup>[28](https://proceedings.mlr.press/v119/katharopoulos20a.html), [29](https://arxiv.org/abs/2102.11174)</sup>

The delta rule writes a correction to the association already stored:

\[
M_t=M_{t-1}+\eta_t(v_t-M_{t-1}k_t)k_t^\top.
\]

The parenthesized term is a prediction error. This update follows directly from a gradient step on \(\tfrac12\|M k_t-v_t\|^2\). It is therefore useful to distinguish plain Hebbian reinforcement from error-correcting associative learning. A representative gated form first computes \(\bar M_t=\alpha_tM_{t-1}\), then writes \(\eta_t(v_t-\bar M_tk_t)k_t^\top\). Gates, normalization, and richer state transitions make these memories more usable; exact implementation conventions vary. <sup>[29](https://arxiv.org/abs/2102.11174), [31](https://arxiv.org/abs/2412.06464)</sup>

This algebra explains why a search limited to papers containing “Hebbian” misses much of the strongest relevant LLM work. The mechanisms often appear under associative memory, fast weights, linear attention, delta networks, and test-time training. It also explains why describing these models as “trained without backpropagation” is usually incorrect: local memory dynamics and the training of the surrounding architecture are separate computations.

**Foundational learning and memory.** Hebb's 1949 proposal inspired an extensive family of learning rules rather than one standardized ML algorithm. The classic developments solve different problems. Oja and Sanger explain stable statistical feature extraction; BCM uses an activity-dependent modification threshold to support selectivity; Hopfield networks show how distributed recurrent connections can retrieve stored patterns from incomplete cues. These results establish computational roles for local adaptation and associative storage. <sup>[1](https://pubmed.ncbi.nlm.nih.gov/7153672/), [2](https://www.cnbc.cmu.edu/~tai/nc19journalclubs/BCM_paper1982.pdf), [3](https://www.sciencedirect.com/science/article/pii/0893608089900440), [4](https://pubmed.ncbi.nlm.nih.gov/6953413/), [10](https://pmc.ncbi.nlm.nih.gov/articles/PMC6475390/)</sup>

The complementary-learning-systems account of McClelland, McNaughton, and O'Reilly is especially useful for ML design: rapid acquisition of individual experiences and slower integration into structured knowledge serve different purposes. The proposed role of reinstatement and interleaving makes clear that avoiding interference requires more than increasing plasticity. A fast memory plus replay or consolidation is a biologically motivated engineering hypothesis; calling any two-memory architecture a faithful hippocampus–cortex model would go beyond this evidence. <sup>[7](https://pubmed.ncbi.nlm.nih.gov/7624455/)</sup>

Spike-timing-dependent plasticity adds temporal structure to correlation. Bi and Poo's experiments showed dependence on spike timing, synaptic strength, and cell type. Izhikevich then demonstrated a computational mechanism combining STDP-related eligibility and dopamine modulation to handle delayed reward. These papers motivate online learning and temporal credit assignment, but do not demonstrate a language model or provide a complete account of learning throughout the brain. <sup>[5](https://pubmed.ncbi.nlm.nih.gov/9852584/), [6](https://pubmed.ncbi.nlm.nih.gov/17220510/)</sup>

**Learning useful representations with local rules.** Krotov and Hopfield's competing-hidden-unit method uses local plasticity with competition to learn features without end-to-end error propagation through the feature learner. Grinberg and colleagues extended related ideas to convolutional image analysis and representation transfer. The important result is useful unsupervised feature formation; a supervised classifier or downstream evaluation remains a separate component. These studies are foundations for local feature learning, rather than evidence of full-scale language-model training. <sup>[10](https://pmc.ncbi.nlm.nih.gov/articles/PMC6475390/), [11](https://arxiv.org/abs/1908.08993)</sup>

SoftHebb derives a probabilistic interpretation for soft winner-take-all learning. The multilayer extension, published at ICLR 2023, reports 99.4% MNIST, 80.3% CIFAR-10, 76.2% STL-10, and 27.3% ImageNet accuracy with up to five hidden layers and an added linear classifier. Those are the paper's configurations and protocols, not a like-for-like ranking against today's strongest supervised models. Its importance is demonstrating learning through several layers without target or feedback signals to those feature layers. The ImageNet result also makes the remaining gap visible. <sup>[12](https://arxiv.org/abs/2107.05747), [13](https://arxiv.org/abs/2209.11883)</sup>

SPHeRe, published at NeurIPS 2025, adds orthogonality and structural-information preservation through a local auxiliary nonlinear projection. Its auxiliary objective uses local backpropagation. It is relevant progress in unsupervised, locally trained representation learning, but it should not be grouped with methods that prohibit gradients everywhere. It illustrates a recurring engineering choice: retain locality between modules while allowing optimization inside each module. <sup>[43](https://proceedings.neurips.cc/paper_files/paper/2025/hash/570c7ef1731e7f243a2e2ec6132b8483-Abstract-Conference.html)</sup>

The 2026 Global-guided Hebbian Learning paper combines competitive Oja-style update magnitudes with the sign of a global task gradient. Its experiments include ImageNet and very deep residual networks. Crucially, the paper explicitly obtains its global direction from a backpropagated gradient. This is evidence that task information improves Hebbian-style updates; it does not remove global credit assignment. Any claimed reduction in computational requirements needs separate measurements of the actual gradient calculation and execution path. <sup>[44](https://arxiv.org/html/2601.21367v1)</sup>

**Brain-inspired alternatives for credit assignment.** Feedback alignment replaces exact transpose feedback weights with fixed random feedback, relaxing one architectural requirement of backpropagation while still supplying an error signal. Predictive coding can produce local activity/error updates that approximate backpropagation under specified assumptions. Equilibrium propagation derives learning from differences between free and weakly nudged equilibria. Dendritic models separate feedforward and feedback influences through neuronal compartments. These approaches address how information about a task could reach local synapses, which simple pairwise correlation leaves unresolved. <sup>[18](https://www.nature.com/articles/ncomms13276), [19](https://pubmed.ncbi.nlm.nih.gov/28333583/), [20](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2017.00024/full), [21](https://elifesciences.org/articles/22901)</sup>

The practical concerns differ. Random feedback can lose effectiveness when scaled; predictive-coding and equilibrium methods may need iterative state inference; symmetric connections or specific approximations can remain important. Bartunov and colleagues' 2018 comparison documented serious scalability limitations for the alternatives they tested. That historical result is a reason to demand larger, controlled comparisons, not proof that all subsequent local-learning research must fail. The 2026 predictive-coding initialization paper directly targets iteration cost by retaining useful information from previous inference. <sup>[23](https://proceedings.neurips.cc/paper/2018/hash/63c3ddcc7b23daa1e42dc41f9a44a873-Abstract.html), [50](https://arxiv.org/abs/2601.20895)</sup>

Hinton's Forward-Forward algorithm trains layer-specific goodness objectives using positive and negative examples. It removes the conventional network-wide backward pass, but learning still depends on local objectives and the construction of useful negative data. Its original demonstrations are deliberately small. E-prop addresses recurrent spiking networks through local eligibility traces combined with learning signals; its approximations should be assessed separately from exact backpropagation through time. Neither paper establishes competitive LLM pretraining through plain Hebbian correlation. <sup>[24](https://arxiv.org/abs/2212.13345), [22](https://www.nature.com/articles/s41467-020-17236-y)</sup>

**Fast plasticity already had language-model applications before transformers dominated.** Schmidhuber's 1992 fast-weight controller separated slowly learned parameters from rapidly changing memory. Ba and colleagues' 2016 work connected fast weights to attending to recent activity. Differentiable plasticity then optimized both ordinary weights and the parameters governing Hebbian plasticity, allowing the outer training procedure to learn an effective inner adaptation mechanism. These are direct predecessors of the modern distinction between a learned representation system and memory updated while processing a sequence. <sup>[8](https://people.idsia.ch/~juergen/fastweights/), [9](https://proceedings.neurips.cc/paper_files/paper/2016/hash/9f44e956e3a2b7b5598c625fcc802c36-Abstract.html), [14](https://proceedings.mlr.press/v80/miconi18a.html)</sup>

Backpropamine adds learned neuromodulation to differentiable plasticity and includes experiments with plastic LSTMs on language modeling. It demonstrates that deciding when and where to write can matter alongside the plasticity rule itself. It remains a gradient-trained system. This is a particularly useful conceptual precursor when designing an adaptive memory module for a modern LM. <sup>[15](https://arxiv.org/abs/2002.10585)</sup>

Rae and colleagues' Hebbian Softmax uses activation memorization to improve rapid learning of rare output classes. On WikiText-103, their table reports test perplexity of 36.4 for their LSTM and 34.3 with the Hebbian component; the 29.2 result additionally uses cache and memory-based parameter adaptation. Attributing the entire improvement to Hebbian learning would be wrong. MicroNet later included Hebbian Softmax in a broader compression pipeline; its aggregate efficiency gains likewise cannot be assigned to that component alone. <sup>[16](https://proceedings.mlr.press/v80/rae18a/rae18a.pdf), [17](https://proceedings.mlr.press/v123/yan20a.html)</sup>

**Hopfield networks explain retrieval, with important limits.** Dense Associative Memory extends classical associative networks and connects their behavior to feature and prototype representations. Modern continuous Hopfield networks provide an energy-based formulation whose update corresponds to an attention operation. Krotov and Hopfield also connect large associative memories to networks with additional hidden neurons and pairwise interactions. These papers are valuable for understanding retrieval, capacity, and attractor dynamics. <sup>[25](https://arxiv.org/abs/1606.01164), [26](https://arxiv.org/abs/2008.02217), [27](https://arxiv.org/abs/2008.06996)</sup>

The equivalence concerns a specified retrieval update, not the entire transformer training algorithm. Exponential storage-capacity statements depend on the model and assumptions about stored patterns and their separation. They do not imply unlimited reliable storage in a fixed finite-precision matrix, nor establish that a deployed LLM can continually acquire arbitrary knowledge without interference. Treat these mathematical results as guidance about architecture, with empirical retrieval tests needed for a proposed implementation. <sup>[26](https://arxiv.org/abs/2008.02217), [27](https://arxiv.org/abs/2008.06996)</sup>

**The strongest scaling evidence: delta-rule language models.** Katharopoulos and colleagues established efficient autoregressive linear attention. Schlag, Irie, and Schmidhuber made the fast-weight equivalence explicit and introduced an error-correcting alternative to additive accumulation. Yang and colleagues' 2024 work made delta-rule training parallelizable over sequence length, addressing a major obstacle to GPU training. Gated DeltaNet then combined selective forgetting with delta writes. The progression is significant because mathematical memory improvements were accompanied by algorithms that made them practical to train. <sup>[28](https://proceedings.mlr.press/v119/katharopoulos20a.html), [29](https://arxiv.org/abs/2102.11174), [30](https://arxiv.org/abs/2406.06484), [31](https://arxiv.org/abs/2412.06464)</sup>

RWKV-7 contributes expressive dynamic state evolution and released language-model results around the 3B scale. DeltaProduct interprets richer recurrence through multiple online update steps per token and products of generalized Householder transformations. These works help address a second limitation beyond raw memory capacity: whether the recurrent state can represent and track the transformations a task requires. Their relationship to Hebbian learning is through associative state updates and online optimization, not a demonstration of biologically faithful whole-network training. <sup>[37](https://arxiv.org/abs/2503.14456), [38](https://arxiv.org/abs/2502.10297)</sup>

Kimi Linear supplies substantial model-scale evidence. Its reported model has 48B total and 3B active parameters, combining Kimi Delta Attention with periodic Multi-Head Latent Attention. Under its matched training recipe, the authors report improved results over the full-MLA comparison, up to 75% lower KV-cache usage, and up to 6× decoding throughput at 1M context. Those maxima are workload- and baseline-specific. The architecture retains full-attention layers, so these results should not be represented as proof that pure finite-state recurrence always replaces attention. <sup>[39](https://arxiv.org/html/2510.26692v1)</sup>

Official Qwen3-Next documentation describes an 80B-total/3B-active model, trained on 15T tokens, using a repeated layout of three Gated DeltaNet layers followed by one gated-attention layer. This is strong evidence of architectural adoption at substantial scale, although a model card alone does not isolate the causal contribution of the delta rule. The August 2026 Qwen3.8-Flash-Next release continues the Gated DeltaNet lineage, paired with sparse attention. Its official documentation also names conventional gradient-based optimizers. <sup>[40](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Thinking), [41](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)</sup>

A systems qualification is essential: constant state size with respect to context length does not mean negligible memory traffic. The 2026 KVBuffer paper examines the cost of repeatedly loading and updating large linear-attention states and proposes buffered, chunkwise serving for Qwen3-Next. It reports latency and serving-capacity improvements under its configurations. This is evidence that practical performance depends on serving implementation, batching, and state movement as well as the recurrence equation. <sup>[54](https://arxiv.org/abs/2605.19049)</sup>

**Test-time learning extends the same idea.** TTT layers make the recurrent state a small learning system: a linear model or MLP whose parameters update on a self-supervised objective during sequence processing. Its 125M–1.3B experiments show competitive short-context perplexity and better use of longer context than the tested Mamba baseline. The August 2025 revision explicitly stresses the substantial computation that richer memory can still require. The outer loop learns representations useful for the inner update; nonlinear TTT can also require gradients inside the memory network. This is broader than a two-factor Hebbian rule. <sup>[32](https://arxiv.org/html/2407.04620v4)</sup>

Titans combines an adaptive neural memory with attention and persistent learned parameters. Its memory uses a gradient-based surprise measure, momentum, and forgetting. The paper reports language-model and retrieval improvements, including needle-in-haystack experiments beyond two million tokens. Those retrieval experiments should not be equated with uniformly reliable reasoning over arbitrary documents of that size. “Long-term” describes the memory's role in context processing and does not automatically mean knowledge persists across independent user sessions. <sup>[33](https://arxiv.org/abs/2501.00663)</sup>

MIRAS generalizes the design space into memory architecture, associative objective, retention mechanism, and learning algorithm. This is a productive framework for comparing mechanisms that otherwise have very different names. Nested Learning and its Hope architecture emphasize multiple update timescales and interacting optimization levels. The latter has a NeurIPS 2025 version, although its arXiv posting is December 31, 2025. Both are useful research frameworks; their breadth of interpretation should not be confused with independent evidence that long-term continual learning has been solved. <sup>[34](https://arxiv.org/abs/2504.13173), [35](https://arxiv.org/abs/2512.24695)</sup>

TTT-E2E, posted in December 2025, adapts a sliding-window transformer through next-token prediction on its context, with meta-training to improve adaptation. It reports 3B models trained on 164B tokens and 2.7× lower latency than full attention at 128K context under its setup. Its reported context-scaling results provide a useful counterweight to assuming every compressed recurrent memory handles longer contexts equally well. This is explicitly gradient-based learning at test time, so it belongs in the broader brain-inspired adaptation discussion rather than the pure-Hebbian category. <sup>[36](https://arxiv.org/abs/2512.23675)</sup>

Reproducibility deserves attention here. Titans Revisited is an independent, lightweight reimplementation that reports mixed results in masked language modeling, time series, and recommendation. Its settings differ from the original autoregressive LM experiments, making it evidence about implementation and generalization limits rather than a direct disproof of every original result. Comparing task, model scale, memory chunking, and optimization budget is necessary before declaring agreement or contradiction. <sup>[53](https://arxiv.org/abs/2510.09551)</sup>

**Direct fine-tuning and agent-memory developments in 2026.** LoRA-HeRO combines local adapter learning, importance-based layer selection, and gradient-based LoRA fine-tuning. It reports up to 48% acceleration for InternVL-1B and 50% for Stable Diffusion in its experiments. Its LLaMA-2-7B table, however, reports a 1.6% average relative accuracy drop from the LoRA baseline; that is not 1.6 percentage points. Its freeze-only ablation reports a 2.2% drop. This supports a speed–quality tradeoff and a component contribution, not universal lossless acceleration. The paper is in ECAI 2025 proceedings; the current publisher page lists August 25, 2026 online publication. <sup>[45](https://journals.sagepub.com/doi/10.3233/FAIA251089)</sup>

HeBiRA, in Findings of ACL 2026, estimates rank-direction importance from the relationship between activations and output gradients, then both prunes and expands adapter capacity. It evaluates language understanding, mathematical reasoning, code generation, and summarization, including LLaMA-2-7B and LLaMA-3-8B. This is a practical Hebbian-inspired allocation mechanism. Its use of output gradients is central, so it does not supply a gradient-free substitute for LoRA training. Replication should compare both parameter budget and total adaptation cost. <sup>[46](https://aclanthology.org/2026.findings-acl.954/)</sup>

HeLa-Mem, an ACL 2026 long paper, operates at another level: an external episodic memory graph strengthens associations through co-activation, while consolidation produces reusable semantic memories. Retrieval combines semantic similarity and spreading activation. It reports improvements on LoCoMo with reduced retrieved context across several LLM backbones. Its graph edges and memory summaries change; the underlying LLM's synapses need not change. For an existing agent application this is a more immediately accessible use of Hebbian ideas than retraining a base model. <sup>[47](https://aclanthology.org/2026.acl-long.625/)</sup>

**Recent work outside large language-model training.** A 2026 audio-classification paper applies selective kernel plasticity to incremental learning, reporting 76.3% overall ESC-50 accuracy across five steps versus 68.7% without that mechanism. Counterstream associative learning, posted in June 2026, explores local supervised association through opposing activity waves, with binarized-MNIST evidence. These studies help characterize adaptation and credit-assignment mechanisms at manageable scale; neither result establishes transfer to general LLM pretraining. <sup>[48](https://arxiv.org/abs/2604.18270), [49](https://arxiv.org/abs/2606.29528)</sup>

The 2025 Engram Neural Network preprint reports explicit differentiable Hebbian traces and experiments including WikiText-103; its abstract describes broadly comparable performance to classical recurrent baselines. A separate 2025 language-structure preprint explores Hebbian tokenization and morphology. These are exploratory contributions. The former's interpretability claims and the latter's language-formation claims deserve tests beyond their reported demonstrations; neither should be promoted to evidence of a competitive general-purpose LLM. <sup>[51](https://arxiv.org/abs/2507.21474), [52](https://arxiv.org/abs/2503.02057)</sup>

SpikeGPT is relevant to brain-inspired language modeling, but its 45M and 216M spiking variants are backpropagation-trained. Spiking activations, local synaptic rules, and energy-efficient hardware are separate design choices. Estimates based on operation counts or assumed hardware energy should be distinguished from measured end-to-end energy on a specified device, including memory movement and training. <sup>[42](https://arxiv.org/abs/2302.13939)</sup>

**How strong is the evidence?** The table below is an analytical assessment. “Strong” refers to support for the narrow proposition stated, not to biological fidelity or an across-the-board advantage over all alternatives.

| Proposition | Assessment | Main reason |
|---|---|---|
| Local stabilized correlation rules can learn useful features | Strong | Theory and multiple image-learning demonstrations [1–3, 10–13] |
| Fast plastic memory can improve adaptation inside a gradient-trained model | Strong for tested settings | Multiple generations of controlled memory and language experiments [14–16, 29, 32] |
| Delta-rule recurrence can be part of a large, useful LM | Strong | Scaled architectures and official model releases [39–41] |
| A pure Hebbian learner can replace competitive LLM pretraining | Not established | No convincing matched-scale demonstration located in the reviewed corpus |
| Hebbian-inspired PEFT can improve adaptation choices | Promising | Direct experiments, but benefits depend on comparison and resource budget [45–46] |
| Associative graphs can improve LLM-agent recall | Promising | Recent direct benchmark results; external-memory mechanism [47] |
| Local updates automatically prevent catastrophic forgetting | Unsupported | Interference and retention remain central design problems [7, 34, 48] |
| Long-context retrieval proves permanent knowledge learning | Unsupported | Context memory, retained weights, and cross-session consolidation are different mechanisms [33–36] |
| A spiking LM is necessarily Hebbian-trained or more energy efficient in deployment | Unsupported | Training method and measured hardware behavior must be examined separately [42] |

**What the literature suggests trying.** For ML/LLM engineering, the most defensible first experiment is a modular memory intervention, with its value measured independently of changes to the rest of the system. The recommendation follows from the comparative evidence above; it is not a result already established for every task.

For an existing LLM agent, compare a HeLa-Mem-style associative graph with ordinary retrieval using the same base model, embeddings, stored information, and retrieval-token budget. Include a strong reranking baseline. Evaluate temporal queries, multi-hop recall, conflicting updates, unrelated distractors, and corrections to old facts. Count memory-construction and consolidation calls as well as inference calls. The goal is to determine whether learned associations add value after controlling for extra summarization and retrieval effort.

For a trainable small LM, compare additive Hebbian memory, delta-rule memory, gated delta memory, and an attention baseline at matched parameter and training-token budgets. Keep the key/value projections, data, optimizer search budget, and implementation quality comparable. Measure both associative recall and ordinary held-out language loss. Vary repeated keys, contradictory values, similar keys, context length, and distractor density to distinguish memory capacity from selective overwriting. Testing both pure recurrence and attention hybrids clarifies which mechanism supplies a gain.

For parameter-efficient adaptation, reproduce a HeBiRA-style rank allocator and, separately, the LoRA-HeRO pipeline. Compare fixed-rank LoRA, a dynamic-rank baseline, and matched-budget freezing or layer selection. Track final quality, trainable parameters, activation memory, preprocessing cost, and total wall-clock time. A gain that disappears when selection overhead or baseline tuning is included is still informative, but supports a narrower claim.

For neuroscience-oriented work, reproduce a competitive local feature learner, then add a clearly specified third factor. Record exactly which quantities a synapse needs: its pre/post activity, shared normalization, output labels, feedback signals, or a global gradient. This makes biological assumptions inspectable and distinguishes improvements from additional task information from improvements in the local rule itself.

A more ambitious research hypothesis is to combine gradient-trained semantic representations, rapidly updated associative memory, and periodic consolidation into slower parameters. Test each component separately before combining them. Evaluate retention over successive tasks, both forward and backward transfer, capacity saturation, and performance after explicit memory resets. Persisting a transient memory into a deployment is a design decision requiring its own evaluation, not an automatic property of a fast-weight equation.

**Questions every promising paper should answer.** What changes during training, within a sequence, and across sessions? Where do the keys, values, targets, gates, and error signals originate? Is there an outer gradient loop, a local gradient computation, or backpropagation through time? Does the comparison hold model size, data, optimization budget, and attention access constant? Are speed and energy measured or inferred? Does the reported continual-learning result retain earlier capabilities after new information arrives? These questions make claims from otherwise incomparable research traditions assessable on their actual merits.

**Suggested reading order.** Start with Oja [1] and the fast-weight/linear-attention connection [29] to understand the equations. Read SoftHebb [13] for a serious attempt at learning local representations, differentiable plasticity [14] for learned adaptation, and Gated DeltaNet [31] for practical memory control. Then read TTT [32], Kimi Linear [39], and TTT-E2E [36] to compare scaling strategies. Finish with HeBiRA [46] or HeLa-Mem [47] depending on whether the intended application is fine-tuning or agent memory. Use the older scalability study [23] and Titans Revisited [53] to practice checking the limits of empirical claims.

**Coverage and limitations.** The scope includes local rate-based plasticity, representative STDP and three-factor foundations, competing-unit deep learning, selected credit-assignment alternatives, fast weights, associative attention, test-time optimization, adapter tuning, agent memory, and selected spiking LMs. The emphasis is English-language primary sources accessible online. Classical sources establish lineage; recent sources were followed through paper references, conference records, and official model documentation. Abstract-level evidence is used only for limited descriptive claims about exploratory work. Material scale, method, and comparison claims above were checked against accessible paper text or official documentation.

The inventory is not a complete census, and no claim is made to have screened every publication, read every reference in full, or replicated experiments. Detailed neuromorphic-device literature, all predictive-coding variants, all continual-learning methods, adaptive resonance theory, self-organizing maps, reservoir computing, and the broader literature on biological learning are outside the depth of this review. Evidence from multimodal, visual, or synthetic tasks is not treated as direct evidence for language-model quality. Recent papers may have limited independent replication, and date differences between preprints, conference versions, and publisher migrations require care.

**Sources and annotated bibliography.** Entries labeled “arXiv paper” identify the accessed research record without asserting a verified conference or journal venue. Publication and posting dates are separated where they differ. The two Qwen entries document architectural adoption and are not peer-reviewed comparative studies.

1. Erkki Oja. [A simplified neuron model as a principal component analyzer](https://pubmed.ncbi.nlm.nih.gov/7153672/). 1982. Journal of Mathematical Biology. Foundational stabilized Hebbian rule; principal-component learning under specified assumptions. Start here for the mathematical distinction between correlation and useful normalized learning.

2. Elie L. Bienenstock; Leon N. Cooper; Paul W. Munro. [Theory for the development of neuron selectivity: orientation specificity and binocular interaction in visual cortex](https://www.cnbc.cmu.edu/~tai/nc19journalclubs/BCM_paper1982.pdf). 1982. Journal of Neuroscience. Sliding modification threshold links activity history to plasticity and selectivity. Biological foundation, not an LLM experiment.

3. Terence D. Sanger. [Optimal unsupervised learning in a single-layer linear feedforward neural network](https://www.sciencedirect.com/science/article/pii/0893608089900440). 1989. Neural Networks. Generalized Hebbian learning extracts multiple eigenvectors. Important for understanding decorrelation and the limits of linear representation objectives.

4. John J. Hopfield. [Neural networks and physical systems with emergent collective computational abilities](https://pubmed.ncbi.nlm.nih.gov/6953413/). 1982. PNAS. Classical recurrent associative memory and retrieval from incomplete cues. Distinguish pattern storage and retrieval from training a deep representation system.

5. Guo-qiang Bi; Mu-ming Poo. [Synaptic modifications in cultured hippocampal neurons: dependence on spike timing, synaptic strength, and postsynaptic cell type](https://pubmed.ncbi.nlm.nih.gov/9852584/). 1998. Journal of Neuroscience. Experimental STDP foundation. Supports timing-sensitive plasticity in the studied neurons, not a universal rule for every brain synapse.

6. Eugene M. Izhikevich. [Solving the distal reward problem through linkage of STDP and dopamine signaling](https://pubmed.ncbi.nlm.nih.gov/17220510/). 2007. Cerebral Cortex. Computational eligibility-trace and neuromodulation mechanism for delayed reward. A useful precursor to three-factor learning.

7. James L. McClelland; Bruce L. McNaughton; Randall C. O'Reilly. [Why there are complementary learning systems in the hippocampus and neocortex: insights from the successes and failures of connectionist models of learning and memory](https://pubmed.ncbi.nlm.nih.gov/7624455/). 1995. Psychological Review. Fast acquisition, slow integration, and interleaving motivate memory consolidation. Does not imply that all fast/slow ML architectures are faithful biological models.

8. Jürgen Schmidhuber. [Learning to control fast-weight memories: An alternative to dynamic recurrent networks](https://people.idsia.ch/~juergen/fastweights/). 1992. Neural Computation; author-hosted paper. Slow controller produces fast memory changes. Historical source for learned fast-weight programming; related technical-report work appeared in 1991.

9. Jimmy Ba; Geoffrey E. Hinton; Volodymyr Mnih; Joel Z. Leibo; Catalin Ionescu. [Using Fast Weights to Attend to the Recent Past](https://proceedings.neurips.cc/paper_files/paper/2016/hash/9f44e956e3a2b7b5598c625fcc802c36-Abstract.html). 2016. NeurIPS 2016. Fast connections store recent activity and support attention-like retrieval. A bridge from biological timescales to sequence-model engineering.

10. Dmitry Krotov; John J. Hopfield. [Unsupervised learning by competing hidden units](https://pmc.ncbi.nlm.nih.gov/articles/PMC6475390/). 2019. PNAS; preprint 2018. Competition and local plasticity produce useful hidden features. Separate unsupervised feature learning from supervised readout evaluation.

11. Leopold Grinberg; John Hopfield; Dmitry Krotov. [Local Unsupervised Learning for Image Analysis](https://arxiv.org/abs/1908.08993). 2019. arXiv paper. Convolutional local learning, patch normalization, and transfer experiments. Relevant to visual representations, not direct LLM evidence.

12. Timoleon Moraitis; Dmitry Toichkin; Adrien Journé; Yansong Chua; Qinghai Guo. [SoftHebb: Bayesian Inference in Unsupervised Hebbian Soft Winner-Take-All Networks](https://arxiv.org/abs/2107.05747). 2021/2022. 2021 preprint; Neuromorphic Computing and Engineering 2022. Probabilistic interpretation of soft competitive learning. Its unsupervised objective should not be confused with access to downstream class labels.

13. Adrien Journé; Hector Garcia Rodriguez; Qinghai Guo; Timoleon Moraitis. [Hebbian Deep Learning Without Feedback](https://arxiv.org/abs/2209.11883). 2022/2023. 2022 preprint; ICLR 2023. Multilayer SoftHebb with image benchmarks and a supervised linear classifier. Key reference for the capability and scaling limits of local feature learning.

14. Thomas Miconi; Kenneth O. Stanley; Jeff Clune. [Differentiable plasticity: training plastic neural networks with backpropagation](https://proceedings.mlr.press/v80/miconi18a.html). 2018. ICML 2018. Learns effective Hebbian plasticity through an outer gradient loop. Demonstrates rapid memory and meta-learning, rather than elimination of backpropagation.

15. Thomas Miconi; Aditya Rawal; Jeff Clune; Kenneth O. Stanley. [Backpropamine: training self-modifying neural networks with differentiable neuromodulated plasticity](https://arxiv.org/abs/2002.10585). 2019/2020. ICLR 2019; linked arXiv posting 2020. Learned neuromodulation controls plasticity; includes recurrent language-model experiments. [Official code](https://github.com/uber-research/backpropamine).

16. Jack Rae; Chris Dyer; Peter Dayan; Timothy Lillicrap. [Fast Parametric Learning with Activation Memorization](https://proceedings.mlr.press/v80/rae18a.html). 2018. ICML 2018. Hebbian Softmax supports rapid binding of rare classes. The best reported language result combines multiple memory mechanisms; inspect the ablation table.

17. Zhongxia Yan; Hanrui Wang; Demi Guo; Song Han. [MicroNet for Efficient Language Modeling](https://proceedings.mlr.press/v123/yan20a.html). 2020. NeurIPS 2019 competition proceedings; PMLR 2020. A compression system that includes Hebbian Softmax, cache, distillation, pruning, and quantization. Aggregate efficiency gains are not a Hebbian-only effect.

18. Timothy P. Lillicrap; Daniel Cownden; Douglas B. Tweed; Colin J. Akerman. [Random synaptic feedback weights support error backpropagation for deep learning](https://www.nature.com/articles/ncomms13276). 2016. Nature Communications. Feedback alignment relaxes exact weight-transport requirements. Error information still reaches hidden layers.

19. James C. R. Whittington; Rafal Bogacz. [An Approximation of the Error Backpropagation Algorithm in a Predictive Coding Network with Local Hebbian Synaptic Plasticity](https://pubmed.ncbi.nlm.nih.gov/28333583/). 2017. Neural Computation. Connects local predictive-coding updates with backpropagation under model assumptions. Read for credit assignment and iterative-inference requirements.

20. Benjamin Scellier; Yoshua Bengio. [Equilibrium Propagation: Bridging the Gap between Energy-Based Models and Backpropagation](https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2017.00024/full). 2017. Frontiers in Computational Neuroscience; preprint 2016. Gradient learning from free and nudged equilibria. Local correlation differences do not remove the need for a task-dependent teaching influence.

21. Jordan Guerguiev; Timothy P. Lillicrap; Blake A. Richards. [Towards deep learning with segregated dendrites](https://elifesciences.org/articles/22901). 2017. eLife. Compartmentalized neurons separate feedforward and feedback influences. A biologically motivated route to deep credit assignment.

22. Guillaume Bellec and colleagues. [A solution to the learning dilemma for recurrent networks of spiking neurons](https://www.nature.com/articles/s41467-020-17236-y). 2020. Nature Communications. E-prop combines local eligibility traces with learning signals. Distinguish exact theoretical decompositions from practical signal approximations.

23. Sergey Bartunov; Adam Santoro; Blake A. Richards; Luke Marris; Geoffrey E. Hinton; Timothy Lillicrap. [Assessing the Scalability of Biologically-Motivated Deep Learning Algorithms and Architectures](https://proceedings.neurips.cc/paper/2018/hash/63c3ddcc7b23daa1e42dc41f9a44a873-Abstract.html). 2018. NeurIPS 2018. Controlled evidence of scaling difficulties for the alternatives tested. Historical comparison, not a verdict on every later method.

24. Geoffrey Hinton. [The Forward-Forward Algorithm: Some Preliminary Investigations](https://arxiv.org/abs/2212.13345). 2022. arXiv preprint. Positive and negative forward passes optimize layer-specific goodness. Small initial demonstrations; not plain pairwise Hebbian learning.

25. Dmitry Krotov; John J. Hopfield. [Dense Associative Memory for Pattern Recognition](https://arxiv.org/abs/1606.01164). 2016. NeurIPS 2016. Higher-capacity associative models connect to feature and prototype recognition. Foundational context for modern memory networks.

26. Hubert Ramsauer and colleagues. [Hopfield Networks is All You Need](https://arxiv.org/abs/2008.02217). 2020/2021. 2020 preprint; ICLR 2021. Continuous Hopfield retrieval connects to attention. Capacity results have model and pattern assumptions; retrieval equivalence is not training equivalence.

27. Dmitry Krotov; John Hopfield. [Large Associative Memory Problem in Neurobiology and Machine Learning](https://arxiv.org/abs/2008.06996). 2020. arXiv paper. Relates large associative memories to hidden-neuron models with pairwise interactions. Useful for assessing biological interpretations of modern Hopfield models.

28. Angelos Katharopoulos; Apoorv Vyas; Nikolaos Pappas; François Fleuret. [Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention](https://proceedings.mlr.press/v119/katharopoulos20a.html). 2020. ICML 2020. Kernelized linear attention has recurrent accumulators. Normalization requires additional state beyond a bare key-value matrix.

29. Imanol Schlag; Kazuki Irie; Jürgen Schmidhuber. [Linear Transformers Are Secretly Fast Weight Programmers](https://arxiv.org/abs/2102.11174). 2021. ICML 2021. Core connection between linear attention and fast weights; replaces additive memory writing with error-correcting delta updates.

30. Songlin Yang; Bailin Wang; Yu Zhang; Yikang Shen; Yoon Kim. [Parallelizing Linear Transformers with the Delta Rule over Sequence Length](https://arxiv.org/abs/2406.06484). 2024. NeurIPS 2024. Parallel training algorithms make delta-rule sequence models practical on modern accelerators. Systems work is central to the scaling story.

31. Songlin Yang; Jan Kautz; Ali Hatamizadeh. [Gated Delta Networks: Improving Mamba2 with Delta Rule](https://arxiv.org/abs/2412.06464). 2024/2025. 2024 preprint; ICLR 2025. Combines forgetting gates with error-correcting memory updates. Direct predecessor of delta-based attention in larger hybrid architectures.

32. Yu Sun and colleagues. [Learning to (Learn at Test Time): RNNs with Expressive Hidden States](https://arxiv.org/abs/2407.04620). 2024. arXiv paper. TTT-Linear and TTT-MLP turn recurrent state into an inner learner. Reports experiments from 125M to 1.3B parameters.

33. Ali Behrouz; Peilin Zhong; Vahab Mirrokni. [Titans: Learning to Memorize at Test Time](https://arxiv.org/abs/2501.00663). 2024/2025. Submitted December 31, 2024; arXiv identifier 2501.00663. Adaptive neural memory uses gradient-based surprise, momentum, and forgetting. Very-long-context retrieval claims are task-specific.

34. Ali Behrouz; Meisam Razaviyayn; Peilin Zhong; Vahab Mirrokni. [It's All Connected: A Journey Through Test-Time Memorization, Attentional Bias, Retention, and Online Optimization](https://arxiv.org/abs/2504.13173). 2025. arXiv paper, April 2025. MIRAS organizes memory architectures by objective, retention, and learning rule. Useful design framework rather than proof of universal continual learning.

35. Ali Behrouz; Meisam Razaviyayn; Peilin Zhong; Vahab Mirrokni. [Nested Learning: The Illusion of Deep Learning Architectures](https://arxiv.org/abs/2512.24695). 2025. NeurIPS 2025 version; arXiv posted December 31, 2025. Multiple optimization timescales and the Hope architecture. Distinguish the conceptual framework from specific demonstrated retention results.

36. Arnuv Tandon and colleagues. [End-to-End Test-Time Training for Long Context](https://arxiv.org/abs/2512.23675). 2025. arXiv paper, December 29, 2025. TTT-E2E adapts a sliding-window transformer with next-token training on context. Reports 3B/164B-token experiments and context-scaling comparisons.

37. Bo Peng and colleagues. [RWKV-7 "Goose" with Expressive Dynamic State Evolution](https://arxiv.org/abs/2503.14456). 2025. arXiv paper, March 2025. Richer recurrent state evolution with released language-model evidence around 3B scale. Related through fast state updates, not pure Hebbian pretraining.

38. Julien Siems; Timur Carstensen; Arber Zela; Frank Hutter; Massimiliano Pontil; Riccardo Grazzi. [DeltaProduct: Improving State-Tracking in Linear RNNs via Householder Products](https://arxiv.org/abs/2502.10297). 2025. arXiv paper; revised title verified October 2025 version. Multiple online update steps produce richer state transitions. Earlier versions used a different subtitle; useful for expressivity versus efficiency.

39. Kimi Team. [Kimi Linear: An Expressive, Efficient Attention Architecture](https://arxiv.org/abs/2510.26692). 2025. Technical report, October 2025. 48B-total/3B-active hybrid KDA–MLA model with matched-recipe comparisons. Speed and KV-cache maxima depend on benchmark context and implementation.

40. Qwen Team. [Qwen3-Next-80B-A3B-Thinking](https://huggingface.co/Qwen/Qwen3-Next-80B-A3B-Thinking). 2025. Official model documentation; accessed September 12, 2026. Documents an 80B-total/3B-active model using a 3:1 Gated DeltaNet/attention layout. Architectural adoption evidence, not an isolated Hebbian ablation.

41. Qwen Team. [Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next). 2026. Official model documentation; release announcement August 26, 2026. Continues Gated DeltaNet with sparse attention and conventional gradient optimizers. Included for current architectural adoption, not leaderboard comparison.

42. Rui-Jie Zhu; Qihang Zhao; Guoqi Li; Jason K. Eshraghian. [SpikeGPT: Generative Pre-trained Language Model with Spiking Neural Networks](https://arxiv.org/abs/2302.13939). 2023. arXiv paper. 45M and 216M spiking language models trained with backpropagation. Separates spiking representations from Hebbian learning and measured energy efficiency.

43. Shikuang Deng; Jiayuan Zhang; Yuhang Wu; Ting Chen; Shi Gu. [Rethinking Hebbian Principle: Low-Dimensional Structural Projection for Unsupervised Learning](https://proceedings.neurips.cc/paper_files/paper/2025/hash/570c7ef1731e7f243a2e2ec6132b8483-Abstract-Conference.html). 2025. NeurIPS 2025. SPHeRe uses structural preservation, orthogonality, and local auxiliary optimization. Includes local backpropagation rather than eliminating gradients everywhere.

44. Wenjia Hua; Kejie Zhao; Luziwei Leng; Ran Cheng; Yuxin Ma; Qinghai Guo. [Hebbian Learning with Global Direction](https://arxiv.org/abs/2601.21367). 2026. arXiv paper, January 29, 2026. Oja-style magnitudes are modulated by global gradient signs. The paper explicitly uses a backpropagated gradient, an essential qualification for its scaling claims.

45. Alexander Demidovskij; Igor Salnikov; Olga Frolova; Aleksei Trutnev; Artyom Tugaryov; Yuri Ignatiev; Vasilisa Blyudova; Egor Zharikov; Irina Novikova. [Going beyond LoRA Fine-Tuning with Hebb Learning: Blazingly Fast and Accurate](https://journals.sagepub.com/doi/10.3233/FAIA251089). 2025/2026. ECAI 2025 proceedings; publisher online date August 25, 2026. LoRA-HeRO combines local updates, layer selection, and gradient fine-tuning. Text-only LLaMA results show a quality tradeoff; inspect the freeze-only ablation.

46. Xing Zhao; Liu Yang; Xi-Le Zhao; Yueqi Yang; Tianqi Jiang. [Hebbian-Guided Bi-Directional Rank Adaptation for Parameter-Efficient Fine-Tuning](https://aclanthology.org/2026.findings-acl.954/). 2026. Findings of ACL 2026, July. HeBiRA reallocates low-rank capacity using activations and output gradients. Direct PEFT evidence, including LLaMA math and code tasks; retains gradient training.

47. Jinchang Zhu; Jindong Li; Cheng Zhang; Jiahong Liu; Menglin Yang. [HeLa-Mem: Hebbian Learning and Associative Memory for LLM Agents](https://aclanthology.org/2026.acl-long.625/). 2026. ACL 2026 long paper, July; preprint April 18. External episodic graph, semantic consolidation, and spreading-activation retrieval. Strong relevance to agent memory; does not train the underlying LLM synapses.

48. Riccardo Casciotti; Francesco De Santis; Alberto Antonietti; Annamaria Mesaros. [Incremental learning for audio classification with Hebbian Deep Neural Networks](https://arxiv.org/abs/2604.18270). 2026. ICASSP 2026, per paper record; arXiv April 20. Selective kernel plasticity improves incremental ESC-50 classification in the reported setup. Domain-specific continual-learning evidence.

49. Andreas Knoblauch. [Supervised Hebbian learning in Deep Counterstream Associative Networks](https://arxiv.org/abs/2606.29528). 2026. arXiv preprint, June 28, 2026. Opposing activity waves support local supervised association. Evidence is binarized MNIST; no demonstrated LLM-scale application.

50. Luca Pinchetti; Simon Frieder; Thomas Lukasiewicz; Tommaso Salvatori. [Faster Predictive Coding Networks via Better Initialization](https://arxiv.org/abs/2601.20895). 2026. arXiv paper, January 28, 2026. Addresses iterative inference cost by improving state initialization. Relevant to scalability of local credit assignment, not direct Hebbian LLM evidence.

51. Daniel Szelogowski. [Hebbian Memory-Augmented Recurrent Networks: Engram Neurons in Deep Learning](https://arxiv.org/abs/2507.21474). 2025. arXiv preprint, July 29, 2025. Explicit differentiable Hebbian traces; includes WikiText-103 with broadly comparable recurrent-baseline performance. Exploratory interpretability and memory contribution.

52. P. Myles Eugenio. [Hebbian learning the local structure of language](https://arxiv.org/abs/2503.02057). 2025. arXiv preprint, March 3, 2025. Exploratory tokenization and morphology model. Its language-structure claims do not establish competitive open-ended language modeling.

53. Gavriel Di Nepi; Federico Siciliano; Fabrizio Silvestri. [Titans Revisited: A Lightweight Reimplementation and Critical Analysis of a Test-Time Memory Model](https://arxiv.org/abs/2510.09551). 2025. arXiv paper, October 10, 2025. Independent reimplementation with mixed outcomes across different tasks. Useful replication evidence, with settings distinct from original autoregressive LM experiments.

54. Longwei Zou; Lin Zhong. [KVBuffer: IO-aware Serving for Linear Attention](https://arxiv.org/abs/2605.19049). 2026. arXiv paper, May 18, 2026. Serving study on Qwen3-Next shows the importance of recurrent-state memory traffic. Constant state with context length does not guarantee low latency.
